Agentic Memory

What an agent remembers is decided by two independent choices: where the memory lives, and how it gets written. The two do not combine freely, and that constraint is where the open problems are.

training paradigm

Objective

What the update optimizes for. The same substrate behaves very differently depending on whether the target is next-token likelihood, a preference signal, a distillation target, or an explicit forgetting term.

Data

What the update is computed from — collected interactions, synthetic rollouts, or the model's own output. Determines what can be written into memory at all, and is where the retain/forget split lives for unlearning.

substrates

KV cache

dynamic · fast

The only store that grows with the interaction. Every token appends, so capacity scales with context length and cost scales with it too — which is why the interesting questions here are eviction, compression and selection rather than capacity.

Model weights

static · slow

Fixed in size and written by gradient descent. Durable but expensive to change, and changing it risks everything else the model knows — the failure mode continual learning and unlearning both work against.

Embedding

static · slow

A fixed-size learned representation. Like the weights it is written by training rather than at inference, so what it encodes is decided before the interaction starts, not during it.

State

static · fast

The recurrent or latent state carried between steps — fixed in size, overwritten in place as the interaction proceeds. Constant cost, but everything not kept is gone.
